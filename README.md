# Ênfase

Repositório utilizado para armazenar projetos, estudos, protótipos e entregas desenvolvidos durante o estágio no Ênfase.

## Estrutura

### 📂 ConversorInformativoSTF
Projeto responsável pela conversão de Informativos do STF para JSON estruturado.

Principais atividades:
- Extração de informações de documentos oficiais
- Processamento e estruturação dos dados
- Geração de arquivos JSON padronizados
- Testes e validações do pipeline de conversão

### 📂 ConversorInformativoSTJ
Projeto responsável pela conversão de Informativos do STJ para JSON estruturado.

Principais atividades:
- Extração de conteúdo dos informativos
- Processamento dos julgados
- Estruturação dos dados em formato JSON
- Integração de técnicas de IA para interpretação de conteúdo quando necessário

## Objetivo

Centralizar os projetos desenvolvidos durante o estágio, mantendo histórico de versões, documentação, testes e implementações realizadas ao longo das atividades.

## Observações

- Este repositório é de uso interno do Ênfase.
- Cada projeto possui sua própria documentação e estrutura interna.
- As implementações podem conter versões experimentais, protótipos e registros de evolução das soluções.
